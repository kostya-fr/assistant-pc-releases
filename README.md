# Assistant du PC : versions publiées

Ce dépôt ne contient que les versions signées de l'Assistant du PC et les deux canaux de mise à jour :

- `latest.json` : version proposée à tous les postes ;
- `beta.json` : version en essai.

Chaque AppImage est jointe à une release `vX.Y.Z` et signée hors ligne. L'application refuse toute version dont la signature ou le numéro de version signé ne correspond pas.
